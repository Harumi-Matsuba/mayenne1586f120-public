# 方法と検証

## 手順
1. **画像**：Gallica の BnF fr. 15573（ark:/12148/btv1b90618780）の246コマ（f. 120r）と247コマ（f. 120v）。紙の右上のフォリオ番号「120」（その左に別の古い番号がある）で、目的の葉であることを確かめた。友清氏の一覧の « p.248 » とはコマ番号が2ずれる。画像はこのリポジトリに含めていない。
2. **傾きの補正と切り出し**：行の水平投影がいちばん鋭くなる角度を探し（`src/angle.py`）、f. 120r は −1.2度、f. 120v は −2.4度で補正した（`src/deskew.py`）。行の基線の位置を指定して、2行ずつ・左右半分に切り出して拡大した（`src/tiles.py`）。
3. **書き起こし**：Brett Burford 氏の見本表 v3（同じ巻 fr. 15573 の Cipher-2 の書簡から作った記号の見本）の名前で、行ごとに記号名を並べた（`data/transcription_*.txt`）。見本にない記号には名前を足した（`data/key.tsv` の inferred・unknown）。原本の区切りの斜線は `/`、行間の書き込みは `^(…)`、線で消された記号は `{…}` で残し、後の2つは解読と採点に使わない。
4. **鍵**：`data/key.tsv` は Burford 氏の `data/key-cipher2.json`（コミット cc0daf74）を元にした。同氏の出どころの印が T（友清氏の表）で始まるものは `table`、E・F（当時の解読との照合）は `burford` とした。この書簡で足した値は `inferred`。根拠の語は4列目にある。
5. **解読**：`src/decode.py` で鍵を書き起こしに当てた（`data/decoded_*.txt`）。読み（[READING.md](READING.md)）は、その出力に語の区切りと句読点を補ったもの。

### 鍵をかき混ぜた対照実験（2ページ合わせて、各1000回）
文字の記号の値を互いに入れ替えた鍵で同じ書き起こしを解読し、フランス語らしさを本物の鍵と比べた。フランス語らしさは、文字3連の対数尤度の平均（`wordfreq` の仏語上位5万語から作成。j→i、v→u に寄せた）。単語記号と、値が2つある記号は採点から外した。

| 条件 | 採点した記号 | 本物の鍵 | かき混ぜた鍵（最小／中央／最大） | 本物以上の回数 |
|---|---|---|---|---|
| 表の記号だけ | 754 | −2.828 | −5.667／−4.895／−3.911 | 0／1000 |
| 表＋Burford 氏の照合 | 834 | −2.833 | −5.756／−5.034／−4.106 | 0／1000 |
| 推定も合わせる | 848 | −2.836 | −5.719／−4.997／−4.236 | 0／1000 |

この比較が示すのは、鍵の値が偶然の割り当てよりずっとフランス語に近い文を出すことまで。個々の記号の読みが正しいかは示さない。

## AI の使用
- 画像の書き起こし、鍵の補い、解読、スクリプト、文書は、Anthropic の Claude（Claude Code、モデル Claude Opus 5.5）が行った。人（リポジトリの管理者）は、対象の選定、画像の保存、公開の判断をした。
- 記号名での書き起こしは、各行を1回読んだもの。複数回の独立した読みや多数決はしていない。人による照合もしていない。
- 書き起こしの途中で、すでに書いた行を鍵で読みながら進めた。似た形の記号は、文脈で選んだ箇所がある（例：r c04 の2文字目を x でなく r と読み、desseing とした。書き起こしでは `r?`）。

## 限界
- **較正をしていない。** 同じ暗号で当時の解読がある書簡（fr. 15573 f. 103v など）の数行を、答えを見ずに読んで一致率を測る予定だった。しかし、準備で f. 103v の縮小画像を開いたときに、左余白の当時の解読と、隣の f. 104r の余白の一部が目に入った。答えを見ないという前提が崩れたので、測らなかった。参考までに、同じ Cipher-2 を同じ方法（AI による1回の目視の書き起こし）で読んだ別の書簡（fr. 15572 ff. 218–219、[Harumi-Matsuba/matignon1586-public](https://github.com/Harumi-Matsuba/matignon1586-public)）では、f. 103v の6行での文字の一致率が74.8%だった。この書簡の書き起こしにも、同じ程度の誤りがありうる。
- 似た形の記号（r と x、8 と 8s、S と ls と hs、f と f2、th と 4t、# と tt）は取り違えやすい。文脈で選んだ分、対照実験は本物の鍵に有利になる。
- inferred の値の多くは、この書簡の中の1〜5か所でしか確かめていない。
- 値が分からない記号と読めない箇所は [OPEN.md](OPEN.md) にある。
