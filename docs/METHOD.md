# 方法と検証

## 手順
1. **画像**：Gallica の BnF fr. 15573（ark:/12148/btv1b90618780）の246コマ（f. 120r）と247コマ（f. 120v）。紙の右上のフォリオ番号「120」（その左に別の古い番号がある）で、目的の葉であることを確かめた。友清氏の一覧の « p.248 » とはコマ番号が2ずれる。画像はこのリポジトリに含めていない。
2. **傾きの補正と切り出し**：行の水平投影がいちばん鋭くなる角度を探し（`src/angle.py`）、f. 120r は −1.2度、f. 120v は −2.4度で補正した（`src/deskew.py`）。行の基線の位置を指定して、2行ずつ・左右半分に切り出して拡大した（`src/tiles.py`）。
3. **書き起こし**：Brett Burford 氏の見本表 v3（同じ巻 fr. 15573 の Cipher-2 の書簡から作った記号の見本）の名前で、行ごとに記号名を並べた（`data/transcription_*.txt`）。見本にない記号には名前を足した（`data/key.tsv` の inferred・unknown）。原本の区切りの斜線は `/`、行間の書き込みは `^(…)`、線で消された記号は `{…}` で残し、後の2つは解読と採点に使わない。
4. **鍵**：`data/key.tsv` は Burford 氏の `data/key-cipher2.json`（コミット cc0daf74）を元にした。同氏の出どころの印が T（友清氏の表）で始まるものは `table`、E・F（当時の解読との照合）は `burford` とした。この書簡で足した値は `inferred`。根拠の語は4列目にある。
5. **解読**：`src/decode.py` で鍵を書き起こしに当てた（`data/decoded_*.txt`）。読み（[READING.md](READING.md)）は、その出力に語の区切りと句読点を補ったもの。

### 鍵をかき混ぜた対照実験（2ページ合わせて、各1000回）
文字の記号の値を互いに入れ替えた鍵で同じ書き起こしを解読し、フランス語らしさを本物の鍵と比べた。フランス語らしさは、文字3連の対数尤度の平均（`wordfreq` の仏語上位5万語から作成。j→i、v→u に寄せた）。単語記号と、値が2つある記号は採点から外した。

| 条件 | 採点した記号 | 本物の鍵 | かき混ぜた鍵（最小／中央／最大） | 本物以上の回数 |
|---|---|---|---|---|
| 表の記号だけ | 754 | −2.828 | −5.667／−4.895／−3.911 | 0／1000 |
| 表＋Burford 氏の照合 | 834 | −2.833 | −5.756／−5.034／−4.106 | 0／1000 |
| 推定も合わせる | 848 | −2.836 | −5.719／−4.997／−4.236 | 0／1000 |

この比較が示すのは、鍵の値が偶然の割り当てよりずっとフランス語に近い文を出すことまで。個々の記号の読みが正しいかは示さない。

## 較正（当時の解読がある書簡での測定、2026-10-20）
- 対象：BnF fr. 15573 f. 104r（Mayenne から国王へ、1586年9月、同じ Cipher-2。Gallica ark:/12148/btv1b90618780 の213コマ）。左余白と下端に当時の解読がある。
- 答えを見ないための手順：f. 120 を読んだのとは別の作業（Claude Code の別のセッション）で、f. 104r の余白も縮小画像も開かずに行った。先に画像の濃い画素の量を列ごとに数え、行の周期（余白の解読は約119画素、暗号は約150画素）で余白と本文の境目（x≈1,400画素）を決めた。各行の左側を白く塗ってから傾き（−1.6度）を直し、本文の範囲だけを切り出して見た。
  - 23行目の左端に、薄い灰色の筆跡（余白の解読の端と思われる2文字ほどの断片）が写った。語としては読んでいない。その後、23・24行目の左端は濃い画素だけを残した二値画像で読んだ（灰色の書き込みは写らない）。
  - 開いた画像は、本文の範囲の上端（フォリオ番号「104」と暗号の1〜3行目）と、18〜24行目の切り出しだけ。
  - `data/key.tsv` の注の1つに、Burford 氏の照合の印として « f. 104r l. 19 'menant' » とあり、書き起こしの前にこれを目にした。
- 書き起こし：暗号の18〜24行目（記号181個）を、この書簡と同じ記号名で、形だけで1回読んだ（`calib/transcription_f104r_l18-24.txt`）。文脈で記号を選んでいない。行頭の記号のうち3つは、余白側を塗った境目で切れて読めなかった。
- 参照（書き起こしを終えてから取得）：
  1. 文字：当時の解読のうち、この7行に当たる « [empor]ter pour plusieurs … qu'il en fallu[st] »（`calib/ref_f104r_l18-24.txt`）。Burford 氏のリポジトリの `data/known-text/f104r-decipherment.txt`（コミット cc0daf74、CC BY 4.0。同氏の注記では Claude が Gallica の画像から目で読んだもの）から写した。この参照を画像で確かめることはしていない（余白を見ることになるため）。
  2. 記号：同氏の `data/known-text/ref-104r-l18-24.txt`（コミット 22ab58c3、CC BY 4.0。当時の解読と照らして確かめたもの）。同氏は行を0から数えるので、同氏の18〜23行目がこの書き起こしの19〜24行目に当たる（`calib/ref_signs_f104r_burford.txt`）。
- 結果（`src/calib.py`）：
  - **文字の一致率69.5%**（参照246文字に対し、編集距離75：置換35、脱落36、余分4）。表の記号だけでは62.6%（編集距離92）。値が2つある記号（`a|n` など）は最初の値で数え、値の分からない記号は不一致とした。
  - 記号の一致率（19〜24行目）：77.4%（参照137記号に対し、編集距離31）。このうち11は、参照の側が行頭の記号を欠いている所（同氏の注記にある、行の帯の当てはめによるもの）で、それを除くと86.1%（編集距離19）。
- 違いの中身（目で分類したもの。同じ箇所が複数に当たることがある）：
  - 1つの記号を2つに読んだ：2o（qui）を「a 0」「a a」と2回、数字の記号 .24.（peu）を「2 q+」と読んだ。
  - 形の近い記号の取り違え：#（r）を 4t（e）と2回（« desgarnie »、« resoluant »）。18行目の頭（当時の解読では « pour plu[sieurs] »）を Gamma・2u（vous de）と読んだ。22行目の頭（当時の解読では « tout des[garnie] »）を Qh・.12.（armée des）と読んだ。ϖ の山を3つでなく2つ（w2）と数えた。
  - 鍵の値の違い：この書き起こしで bslash（＼ に o）と名付けた記号を、Burford 氏は curl とし、当時の解読でも2か所とも pour（« emporter pour »、« parle pour »）。この書簡の鍵では bslash＝a、curl＝o と推定していた。λ は « deux » の位置にあり、Burford 氏の鍵の x（dx＝deux）と合う。この書簡の鍵では q とした。
  - 暗号の綴りと当時の解読の綴りの違い（読みの誤りではない。Burford 氏の記号の参照も同じ記号）：faicts／faictz、principales、dificultes、restent、Guyenne、estans、campes など。
  - 地名（Xaintonge、Poitou）の記号は、鍵に値がないか、読めなかった。行頭で切れた記号3つ。
- この較正の結果に合わせて、f. 120 の書き起こしや鍵は直していない。上の bslash・curl・λ・# と 4t の違いは、f. 120 の読み（例：r c11 の « a venir » は « pour venir » かもしれない）に関わるので、[OPEN.md](OPEN.md) の確かめていないことと合わせて、次の見直しで扱う。
- 意味：記号の形だけで1回読んだ書き起こしと鍵を合わせると、文字で3割ほどの誤りを含みうる。f. 120 では文脈で記号を選んだので、誤りはこれより少ないと見込まれるが、確かめていない。matignon1586-public の f. 103v での較正（74.8%）と同じ程度である。

## AI の使用
- 画像の書き起こし、鍵の補い、解読、スクリプト、文書は、Anthropic の Claude（Claude Code、モデル Claude Opus 5.5）が行った。人（リポジトリの管理者）は、対象の選定、画像の保存、公開の判断をした。
- 記号名での書き起こしは、各行を1回読んだもの。複数回の独立した読みや多数決はしていない。人による照合もしていない。
- 書き起こしの途中で、すでに書いた行を鍵で読みながら進めた。似た形の記号は、文脈で選んだ箇所がある（例：r c04 の2文字目を x でなく r と読み、desseing とした。書き起こしでは `r?`）。

## 限界
- 較正は f. 104r の7行（181記号）だけで、1回の書き起こしによる。結果は上の「較正」にある（文字の一致率69.5%、表の記号だけで62.6%）。文字の参照は他者が目で読んだ当時の解読で、画像で確かめていない。f. 120 を読んだ作業では、準備で f. 103v の縮小画像を開いたときに当時の解読の一部が目に入ったので、較正は余白を見ていない別の作業で行った。
- 似た形の記号（r と x、8 と 8s、S と ls と hs、f と f2、th と 4t、# と 4t と tt、2o と「a 0」）は取り違えやすい。較正では # と 4t、2o の取り違えが実際に起きた。文脈で選んだ分、対照実験は本物の鍵に有利になる。
- inferred の値の多くは、この書簡の中の1〜5か所でしか確かめていない。
- 値が分からない記号と読めない箇所は [OPEN.md](OPEN.md) にある。
