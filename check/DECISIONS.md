# 画像での確かめ（照合の記録、2026-10-20）

1回目の書き起こし（data/）と、Codex の3回目の実行（独立の読み、当時の codex/transcription_codex_*）の値の食い違い77か所を、Codex（codex-cli 0.163.0-alpha.10.2、既定のモデル）と Claude Sonnet に、まっすぐにした行の画像と見本表で、形だけで判断させた（問い：CHECK_PROMPT.md、答え：answers_codex.txt・answers_sonnet.txt）。A＝1回目の形、B＝Codex の読みの形、N＝決められない。
Codex の実行記録にはコマンドの実行がなく、画像は1枚ずつ渡した。

判断の決まり：2つのモデルがそろって B と答え、しかも形の読み違いであるときだけ直した。そろって B でも、見本表の近い名前を選ぶと値が変わって文脈と合わなくなる組（curlo と curl、2 と 2u、6b と B、9 と d）は、同じ形の記号の値の問題として扱い、直していない（docs/OPEN.md）。
